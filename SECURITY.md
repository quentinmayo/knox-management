# Security reports

Use GitHub **Security → Report a vulnerability** for sensitive reports. If private reporting is unavailable, open an issue requesting a private reporting channel without including exploit details or real credentials.

This is an initial, unaudited single-operator interface. A console administrator acts with its configured Knox principal's privileges. Reports about authentication bypass, cross-origin actions, secret disclosure, and TLS are especially useful. Reproduce with generated data. Never include real keys, passwords, tokens, private certificates, or backend secret responses.
